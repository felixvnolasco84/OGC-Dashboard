# Capturas de comentarios

Componentes reales de la aplicación, ejecutados localmente con datos simulados. La fotografía de fondo es ilustrativa.

| Prefijo | Flujo |
| --- | --- |
| `photo` | Conversación por fotografía de Bitácora |
| `program` | Comentarios de partida/familia de Programa |
| `delete` | Confirmación identificando comentario y destino |
| `edit` | Editor mostrando actual y propuesta |
| `error` | Fallo visible con borrador conservado |
| `success` | Resultado después de guardar |
| `discard` | Protección del borrador al cerrar |
| `offline` | Conexión perdida con borrador conservado |
| `conflict` | Cambio externo detectado antes de guardar |

Los sufijos `1440`, `390` y `320` indican ancho del navegador en píxeles. `validation.json` registra los 21 grupos de pruebas de interfaz aprobados y sus 30 capturas. `MENSAJE-PARA-RO.txt` contiene el texto aparte del problema resuelto.

La implementación permanece local; no se desplegó ni se usaron datos reales del proyecto para estas capturas.
